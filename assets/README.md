# Assets

Visual resources used by the KeychainOS interface.

- `icons/` — Application and status icons
- `fonts/` — Source and converted fonts
- `images/` — Wallpapers, splash screens and artwork
- `themes/` — Theme definitions and associated resources

The primary display target is 240 x 320 pixels. Large runtime assets should normally live on the microSD card rather than in ESP32 flash.

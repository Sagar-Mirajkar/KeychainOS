# Project Context

KeychainOS began from a recurring need: having computer capability available when a phone cannot complete a task and a laptop or unrestricted office PC is unavailable.

The project combines an instant, low-power ESP32-S3 interface with a future, on-demand Linux subsystem. The Linux subsystem is a capability multiplier rather than the primary everyday interface.

The user experience must hide processor, bus and filesystem complexity. A user should see actions such as `Start Computer Mode`, `Use USB Device`, `Open Files` and `Safe to Remove`, rather than internal technical terminology.

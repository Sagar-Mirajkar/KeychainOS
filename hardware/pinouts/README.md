# Pinouts

## Fixed LCD Driver Board assignments

- GPIO1 — LCD/SD SCLK
- GPIO2 — LCD/SD MOSI
- GPIO42 — LCD/SD MISO
- GPIO39 — LCD CS
- GPIO41 — LCD DC
- GPIO40 — LCD reset
- GPIO6 — LCD backlight
- GPIO38 — SD CS
- GPIO15 — Touch SDA
- GPIO7 — Touch SCL
- GPIO16 — Touch reset
- GPIO17 — Touch interrupt

Pending assignments must be documented before modules are connected.
